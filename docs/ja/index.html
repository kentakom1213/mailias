サービスごとに、違うアドレスを。

自分のドメインでメールアドレスを作れます。

名前 github → 生成されるアドレスの例 github-v1-vtabvg6w@m.example.com
セットアップを見る Chrome 版 Firefox 版

使い方

最初の設定後は、アドレスを作るたびに Cloudflare を操作する必要はありません。

mailias
英数字とハイフンを使えます。

生成されたアドレス デモ用のアドレスです。

作ったアドレスをそのままサービスの登録に使えます。

しくみ

  1. 01

    拡張機能でアドレスを作る

    github-v1-vtabvg6w@m.example.com

  2. 02

    Cloudflare Worker がアドレスを検証する

  3. 03

    正しいアドレスなら、いつもの受信箱へ転送する

発行したアドレスの一覧はあなたの端末にのみ保存されます。

アドレスには、秘密キーから作った短い認証タグが 含まれています。Worker はこのタグを検証します。

アドレス管理用のデータベースや自前のサーバーは必要ありません。

設定

mailias を使うには、Cloudflare で管理している独自ドメインが必要です。

  1. 01

    拡張機能をインストール

    Chrome 版 Firefox 版
  2. 02

    Cloudflare Worker を設定

    拡張機能で作った秘密キーと、 転送先のメールアドレスを設定します。

    Worker をデプロイ ↗
  3. 03

    Email Routing を設定

    対象ドメインの catch-all を mailias Worker に接続します。
