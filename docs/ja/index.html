サービスごとに，違うアドレスを．

自分のドメインで，サービスごとにメールアドレスを作れます．
Cloudflare Workerが宛先アドレスを検証し，いつもの受信箱へ転送します．

名前github → 生成されるアドレスの例 github-v1-vtabvg6w@m.example.com

しくみ

  1. 01

    サービスごとのアドレスを作る

    拡張機能で，サイトごとのメールアドレスを生成します．

  2. 02

    Cloudflare Worker でアドレスを検証する

    メールが届くと，Worker がアドレスに含まれる認証タグを検証します．

  3. 03

    受信箱へ転送する

    アドレスが正しければ，メールを設定した転送先へ送ります．

  • 自分のドメインと Cloudflare だけで運用できます．
  • 発行したアドレスの一覧をサーバー側に保存する必要はありません．

使い始める

Cloudflare で管理しているドメインと，転送先のメールアドレスが必要です．

  1. 01

    拡張機能をインストールする

    Chrome または Firefox に mailias をインストールし，設定画面を開きます．

    Chrome 版を入手 Firefox 版を入手
  2. 02

    秘密キーを作って保管する

    拡張機能で秘密キーを作り，パスワードマネージャーなどに保存します．秘密キーは必ず保管してください．失うと，同じアドレスを生成できなくなります．

  3. 03

    Worker をデプロイして設定する

    Worker をデプロイし，秘密キーと転送先のメールアドレスを設定します．

    Deploy Worker to Cloudflare ↗
  4. 04

    Email Routing を設定する

    対象ドメインの Email Routing で，catch-all を mailias Worker に接続します．

  5. 05

    サービス用のアドレスを作る

    区別しやすい名前を入力してアドレスを作り，そのアドレスをサービスに登録します．
