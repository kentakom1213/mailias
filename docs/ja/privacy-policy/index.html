プライバシーポリシー

最終更新日：2026年9月19日

適用範囲

このポリシーは，mailias のブラウザ拡張，プロジェクトのウェブサイト，および利用者自身の Cloudflare アカウントにデプロイする標準の Worker におけるデータの取り扱いについて説明します．mailias の開発者は，利用者のエイリアスやメールを管理する中央サービスを運営していません．

端末内で扱うデータ

拡張機能は，メールドメインや Worker URL などの設定情報，秘密キー，およびサイトとエイリアスの対応情報を端末内に保存します．対応情報にはラベルの作成日時と最終コピー日時が含まれます．

現在のサイトに対応するエイリアスを表示するため，ポップアップを開いたときに現在のタブの URL からサイトのドメインを取得します．タブの完全な URL は保存しません．

秘密キーはエイリアスの生成や設定の確認に端末内で使用します．Worker や開発者へ秘密キーを送信することはありません．

対応表をエクスポートした場合，エクスポートファイルに秘密キーは含まれません．

Worker との通信

拡張機能は，利用者が設定した Worker へ接続し，到達可能性や設定状態を確認します．この通信には，必要に応じて設定済みのメールドメインが含まれます．秘密キーや現在のタブの URL は送信しません．

通常のネットワーク通信と同様に，Cloudflare は接続元の IP アドレスやリクエストに関する情報を処理する場合があります．

メールの処理

秘密キーと転送先メールアドレスは，利用者自身の Cloudflare 環境に設定します．Cloudflare Email Routing と Worker が受信メールを処理し，有効なエイリアス宛てのメールを指定したアドレスへ転送します．

拡張機能自体は受信箱やメール本文を読み取りません．標準の Worker は発行済みエイリアスの一覧をデータベースに保存しません．Cloudflare 上のログなどの保存については，利用者の設定および Cloudflare のポリシーが適用されます．

外部サービス

拡張機能は，広告，利用状況の解析，トラッキングのためにデータを開発者へ送信しません．

Worker とメール転送には Cloudflare が利用され，転送後のメールは利用者が指定したメールサービスによって処理されます．これらのサービスには，それぞれの利用規約とプライバシーポリシーが適用されます．

データの削除

端末内の設定，エイリアスの対応情報，秘密キーは，mailias をリセットするか，ブラウザから拡張機能のデータを削除することで削除できます．個別の対応情報は設定画面から削除できます．

拡張機能内のデータを削除しても，Cloudflare や転送先のメールサービスに保存されているデータには影響しません．これらのデータは，各サービスの設定やポリシーに従って管理してください．

ウェブサイト

プロジェクトのウェブサイトでは，アクセス解析やトラッキングを行っていません．ページの配信に伴い，ホスティング事業者が IP アドレスやリクエストに関する情報を処理する場合があります．
