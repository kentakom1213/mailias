A different address for every service.

Create email aliases on your own domain. Your Cloudflare Worker verifies each address and forwards valid messages to your usual inbox.

How it works

  1. 01

    Create an address for a service

    Aliases are generated locally in your browser.

  2. 02

    Verify the address tag

    When mail arrives, your Cloudflare Worker checks the tag in its recipient address.

  3. 03

    Forward to your inbox

    Valid messages are forwarded to the destination you configured.

  • Use your own domain without a separate email alias provider.
  • The Worker does not need an alias database. Site labels are managed locally in the extension.

Get started

You need a domain managed with Cloudflare and a destination email address.

  1. 01

    Install the extension

    Install mailias for Chrome or Firefox and open its settings.

    Download for ChromeDownload for Firefox
  2. 02

    Create and back up your secret key

    Generate a secret key in the extension and save it in your password manager. You need the same key to regenerate existing aliases.

  3. 03

    Deploy and configure your Worker

    Deploy the Worker. Set MAILIAS_SECRET to your secret key as a Secret, and MY_ADDRESS to your destination email address as a regular Variable.

    Deploy Worker to Cloudflare ↗
  4. 04

    Set up Email Routing

    If you use a subdomain, add it first. Configure the catch-all rule for your mail domain to send messages to your mailias Worker.

  5. 05

    Create an address for a service

    Enter a recognizable label, generate the address, and use it to register with the service.
