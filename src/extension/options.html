Step 1 of 7

Connect your Worker

Deploy mailias to Cloudflare first，then paste the Worker URL here．mailias does not need a Cloudflare API token in the extension．

Deploy to Cloudflare
  1. After deployment，open the Worker in Cloudflare and go to Domains (or Settings → Domains & Routes)．
  2. Make sure the workers.dev domain is enabled，or add a Custom Domain．The extension needs a public HTTPS URL for /health．
  3. Open that URL once in a normal browser tab，then paste the origin below．
Open Workers & Pages
Step 2 of 7

Choose your mail domain

Enter the domain that will receive mailias addresses，for example m.example.com．

Step 3 of 7

Set up your recovery key

Create a new key for a new installation，or restore an existing key from your password manager．

New setup

Generate a random recovery key locally in this extension．

Restore existing setup

Paste the recovery key already stored in your password manager．

Step 4 of 7

Back up the recovery key

Save this key in your password manager before continuing．After this step，mailias stores only a non-exportable key in the extension．

This is the only time mailias will show the raw recovery key．

Copy the recovery key and save it manually in your password manager．Keep that entry as your only recovery copy．

Step 5 of 7

Configure the Worker

Open the Worker in Cloudflare and add the two runtime bindings below．

  1. Open Workers & Pages and select your mailias Worker．
  2. Open Settings → Variables and Secrets．
  3. Add MAILIAS_SECRET as a Secret using the recovery key from your password manager．
  4. Add MY_ADDRESS as a normal Variable containing your own destination inbox address．It is not a Secret．
  5. Select Deploy in Cloudflare．
Open Cloudflare Workers

Step 6 of 7

Connect Email Routing

Configure Email Routing for your mail domain．If you use a subdomain，enable it first，then route the catch-all address to the mailias Worker．

  1. Open Email Routing for the apex domain that contains your mail domain．
  2. If your mail domain is a subdomain such as m.example.com，open Settings → Subdomains and add that subdomain first．Wait until it is ready．
  3. Open Routing Rules for the mail domain and enable the Catch-all rule．
  4. Set the catch-all action to Send to a Worker，select your mailias Worker，and save．
Open Email Routing
