1．Create recovery key

Create a recovery key locally．The key never leaves this extension unless you copy it．

This key cannot be read back from the extension． Save it in your password manager before continuing．It is the only recovery copy．

Restore existing setup

Use the recovery key stored in your password manager．

2．Deploy and connect the Worker

Deploy first，then configure the runtime bindings in Cloudflare．The extension does not store a Cloudflare API token．

Deploy to Cloudflare Open Cloudflare dashboard

After deployment，set MAILIAS_SECRET from your password manager and FORWARD_TO to a verified Email Routing destination．

3．Connect Email Routing

Route the mail domain catch-all to this Worker in Cloudflare Email Routing．mailias cannot verify that rule through /health，so confirm it here after saving the rule．

Open Email Routing
